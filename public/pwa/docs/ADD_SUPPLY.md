# Добавление новых поставок

Есть 3 способа добавить поставку.

## Способ 1. Через админ-экран PWA (рекомендуется)

1. Войдите бейджем администратора (`20ADMIN` или бейдж с role=admin).
2. На экране поставок нажмите **⚙ Админ**.
3. В блоке **➕ Новая поставка**:
   - Введите название (например, `Wildberries — Парфюм Март 2025`).
   - Вставьте состав в формате TSV/CSV (из Excel: скопируйте ячейки, вставьте).
4. Нажмите **Добавить поставку**.

Формат колонок (через Tab или `;`):

```
Наименование товара  ШК Юнит        Артикул   Юнитов  Страна     Пупырка
Туалетная вода Dior  4895165564564  art-DS100  72     ФРАНЦИЯ    25х20
Шампунь Сиберика     4607034590012  art-NS400  60     РОССИЯ     25х20
```

- **Страна `РОССИЯ`** → режим поштучного сканирования (печать не нужна).
- **Любая другая страна** → режим печати пула кодов (нужен файл в `printer/labels/<ШК>.txt`).
- Первая строка с заголовками («Наименован», «ШК», «Артикул», «Страна») распознаётся и пропускается автоматически.

## Способ 2. Вручную через Google Sheets

1. Откройте таблицу, лист **Поставки**.
2. Добавьте строку: `SUP-003 | Название | 2025-01-15 | TRUE | Поставка_3`.
3. Создайте лист **Поставка_3** с заголовками (см. [TABLE_STRUCTURE.md](TABLE_STRUCTURE.md)).
4. Заполните строки состава (колонки 1–9). Служебные колонки 10–17 можно оставить пустыми — PWA/GAS заполнит их.
5. Поставка сразу появится в PWA (is_active=TRUE).

## Способ 3. Через GAS (программно)

Вызовите из редактора Apps Script:

```javascript
adminAddSupply({
  name: 'Ozon — Парфюм Апрель',
  tsv: 'Туалетная вода Dior 100мл\t4895165564564\tart-DS100\t72\tФРАНЦИЯ\t25х20\n' +
       'Шампунь Сиберика 400мл\t4607034590012\tart-NS400\t60\tРОССИЯ\t25х20'
});
```

## Файлы пулов кодов (для импортных товаров)

Для каждой позиции с страной ≠ РОССИЯ поместите в `printer/labels/` текстовый файл, имя которого **содержит ШК юнита** (например `4895165564564.txt` или `4895165564564_001.txt`).

Формат файла — по одной строке на код маркировки:

```
0104895165564564211234567890110250625
0104895165564564211234567891110250625
0104895165564564211234567892110250625
...
```

Python-сервер печати читает этот файл и печатает каждый код в 2 копиях с порядковым номером.

## Активация/деактивация

В админ-экране переключатель справа от поставки включает/выключает её видимость в PWA. Деактивированная поставка не пропадает из таблицы — её просто не видно сотрудникам.
